# 扩展工作周 v0.3

声音克隆与真人队友语音入口目前置灰，暂未开放。默认角色朗读及 Studio 录制仍可用。开源版保留默认免注册模式、可选账号系统和 ADMIN_EMAIL 管理员配置。

本版本在网页现有规则上补充玩法，不声称与原作隐藏规则、数值或资产完全一致。旧存档继续使用经典规则；新玩家、新建多人房间和“重新入职”使用扩展规则。重新入职会替换单人进度，可先导出旧存档。

## 玩法与入口

| 能力 | 实现与使用方式 |
| --- | --- |
| 情境对话 | 通话依次需要了解顾虑、解释方案、确认意愿。AI 返回语义意图、态度及是否与已有事实矛盾；状态机掌管信任、疑虑与阶段。连续重复同一句不会推进。离线模式也可以完成流程。 |
| 八类业务 | Identity 比对记录并处理冲突；Credit 核算账本并验证三项编号；AnyViewer 检查便签、目录、版本并撤销模拟连接；Gift 拼合券面、计算库存；Charity 选择补给并分箱；Corn 读供应变化、设置仓位；Prize 筛选候选人、排序程序；Retirement 选择路线、计算补给。 |
| 调查后结算 | 服务器检查调查步骤，不能直接填编号绕过。错误消耗信任和耐心、增加疑虑；任务只能结算一次。 |
| 随机事件 | 第二天起使用存档种子决定事故类型和时机。普通路线每天最多两次计划事故，混乱路线三次。下一次事件时机受风险影响。可疑附件与试探者另可触发病毒。 |
| 事故处置 | 安全中心显示应急顺序并提供正确步骤和干扰选项。顺序错误增加风险并缩短应急时间；超时损失15秒工作时间和通话耐心。停电仍须到配电箱，物品可用于排障。 |
| 工作路线 | 上班前和每日考核后选择：客户关怀增加35秒耐心并加快疑虑下降；效率竞赛收入增加25%、耐心减少15秒；混乱奖金收入增加40%、事件更频繁。商店绩效升级与路线收益相乘。 |
| 团队调度 | Dispatch 显示队友线路、当前案件线索和事故。发出转接请求后，对方入座并接受才转移通话。请求20秒有效，忙线或AI正在回应时不转接；保留调查与对话，不复制任务。 |
| 协作支援 | 协助调查给队友增加20秒耐心、减少12点疑虑；支援事故完成一个应急步骤。支援停电必须靠近配电箱。每人支援冷却20秒。 |
| 公开大厅 | 房主勾选“在公开大厅招募队友”。大厅列出仍活跃、未满、未结束的房间，每15秒刷新；45秒未更新的列表记录不展示。开局后可中途加入。主动离开释放工位，保留当日贡献及返回进度；网络断线仍保留重连席位。 |
| 人物工作坊 | 主菜单或桌面 Workshop 可添加人物、导入导出JSON。每个工作周最多8人，姓名40字、背景600字、顾虑200字。联机人物库与路线由房主设置。新来电读取自定义人物的姓名、背景、开场和音色。 |
| WAV音色 | 工作坊可上传有权使用的10–120秒PCM WAV，最大8MB。通过ElevenLabs IVC创建；每账号最多3个音色。只有服务商无需额外验证的音色才会激活。默认音色仍可用。 |
| Studio | 录屏选择游戏标签页，可同时包含标签页声音及自己的麦克风；也可单独录制自己的原声。最长3分钟或约64MB时自动停止；每账号本浏览器素材库最多20段。播放、下载和删除均可在Studio操作。 |
| 考核展现 | 老板按业绩比例给出不同点评，显示实际通话片段、排障与协助统计。保留原有文字合成回放，并可展开本工作周当天的真实录制。到考核时自动停止录制。 |
| 照片与物理 | 拍照窗口可打印为共享物体，拾取、丢下、投掷，最多8张。图片缩成128×96的JPEG再同步。站立人物受击后使用9节点、10约束的简化布娃娃模拟，结束后恢复站立。 |
| 场景 | 会议室增加老板角色；火灾增加烟雾；原有灯光、火焰与突袭闪光继续使用。新增调查台、应急面板、团队调度、工作坊及录制窗口。 |
| 公开指南 | `/guide/` 下的入门、联机、工作坊和FAQ无需登录，提供静态HTML、标题、描述、canonical、robots及sitemap。指南正文目前为中文。 |

新界面的主要文案和案件动态线索已加入英语、中文、巴西葡语、日语和西班牙语。用户自定义人物资料保持原文，AI回复使用玩家当前语言。

## 外部服务与数据

- D1新增迁移：`0005_public_lobbies.sql`，包含公开房间索引和自定义音色归属。上线前执行现有 `npm run db:remote`；现有 `deploy:ci` 已包含迁移步骤。
- 声音克隆：设置 Worker secret `ELEVENLABS_API_KEY`。如果站点主TTS已经使用ElevenLabs，也可沿用其服务端密钥。若主TTS是MiniMax，可以保持不变、单独设置克隆密钥。克隆后的角色通过ElevenLabs播放。
- WAV样本发送至ElevenLabs，不写入D1。D1只保存音色编号、归属、名称和创建时间。删除音色时先向服务商删除，成功后再移除本站记录。
- 自定义音色默认仅归属账号可用；同房间玩家当前来电使用该音色时，服务端核验房间成员身份和来电后允许播放。客户端不能传任意音色越权使用。
- Studio录音录像在IndexedDB本地保存，不上传服务器、不进入云存档。清除浏览器数据会删除素材，请自行下载。浏览器未分享标签页声音时，录屏不包含该音轨；单独“录制我的原声”只录玩家麦克风。
- TURN使用既有 `TURN_KEY_ID`、`TURN_API_TOKEN`。本次没有更换线上服务凭据，也没有对真实公网复杂NAT环境作保证。
- 本次未调用付费克隆服务生成真实音色，没有发布到生产站。真实服务套餐、样本质量和延迟需要配置后验收。

## 验证

- `tests/campaign.test.ts`：所有业务的前置条件、调查与结算、重复话术、语义意图与矛盾、随机事件、导入校验、照片、布娃娃、多语言线索。
- `tests/room-expansion.test.ts`：真实OfficeRoom处理逻辑配合内存SQLite与WebSocket测试替身，覆盖转接确认、过期、AI忙碌保护、协助冷却、配电箱距离、公开房间权限、迟到加入、离开与返回后的业绩和工位。
- `tests/voices.test.ts`：WAV解析、授权确认、服务配置、上传格式、归属、服务商验证与失败处理，使用模拟服务响应。
- `tests/expansion-browser.html`：仅开发环境的界面夹具，不打入生产入口。使用真实组件和规则引擎，模拟账号与外部接口。
- 启动界面夹具服务器：`npx vite --config tests/browser.vite.config.ts`；另一个终端执行 `node scripts/test-expansion-browser.mjs`。需要本机Chrome；测试使用浏览器合成麦克风，不访问真实麦克风，不调用云端AI。截图输出至 `.reference/expansion/`。
- 公开指南由 `node scripts/build-guides.mjs` 生成；新增多语言词条源在 `scripts/localize-expansion.mjs`，运行后执行 `npm run check:i18n`。

## 实现边界

这套扩展提供可操作的网页机制：远程电脑始终是虚构文件调查；布娃娃使用简化约束与地面碰撞，不是原作精确骨骼和家具网格碰撞；老板演出使用程序化人物与台词，不是原版动画资产。录屏和麦克风仍由用户通过浏览器选择与授权。开放大厅的生产负载、跨网络语音、真实克隆音色质量需要上线环境验收，不能用单元测试或界面夹具替代。

## 自托管指南域名

运行 `SITE_ORIGIN=https://your-domain.example node scripts/build-guides.mjs` 生成公开指南、canonical 和 sitemap（PowerShell 使用 `$env:SITE_ORIGIN`）。默认使用 example.com 占位地址，上线前替换。现有 D1 数据库执行 0005 迁移，不要替换已有数据库绑定。
